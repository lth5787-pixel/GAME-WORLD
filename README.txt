MOBILE GAME WORLD
=================

실행 방법
1. ZIP 파일 압축을 풉니다.
2. mobile_game_world 폴더 안의 index.html을 더블 클릭합니다.
   또는 Visual Studio Code에서 폴더를 열고 Live Server 확장 프로그램으로 실행합니다.

파일 구성
- index.html : 웹사이트 화면 구조
- style.css  : 디자인 및 반응형 레이아웃
- script.js  : 게임 데이터, 검색, 필터, 정렬, 즐겨찾기, 상세정보, 스토어 링크

포함 기능
- Android / iOS 함께 표시 및 플랫폼 필터
- 장르별 필터, 무료/유료 필터
- 게임 이름/장르 검색
- 인기순/평점순/출시일순/이름순 정렬
- 게임 상세 정보 모달
- Google Play / App Store 검색 링크
- 랜덤 게임 추천
- 브라우저 localStorage 기반 즐겨찾기

중요 안내
현재 등록된 게임의 평점, 용량, 최소 사양은 화면 구성 예시를 위한 참고값입니다.
게임 업데이트, 기기, 국가/지역에 따라 달라질 수 있으므로 실제 운영 전 공식 스토어의 최신 정보로 수정하세요.
스토어 버튼은 해당 게임의 스토어 검색 결과로 연결됩니다. 정확한 앱 상세 주소를 확보하면 script.js의 play / app URL을 교체하면 됩니다.

게임 추가/수정
script.js 상단의 games 배열에 있는 객체를 복사해 추가하거나 값을 수정하면 됩니다.

[게임 대표 이미지]
게임 카드에 이모지 대신 Apple App Store 검색 API에서 확인한 실제 앱 대표 이미지(앱 아이콘)를 자동으로 불러오도록 변경했습니다. 최초 이미지 로딩에는 인터넷 연결이 필요합니다. 한국 스토어에서 찾지 못하면 미국 스토어를 추가 검색합니다. 앱스토어에 등록되지 않은 게임이나 이름이 다른 게임은 대표 이미지가 표시되지 않을 수 있으며, 해당 게임의 공식 스토어 이미지 확인이 필요합니다.

추가 업데이트: 기존 110개에 모바일 게임 100개를 추가해 총 210개로 확장했습니다. 새로 추가된 항목의 출시 연도·평점·용량·기기 사양은 참고용 또는 스토어 확인 항목이며, 실제 정보는 각 앱 스토어에서 확인하세요.
